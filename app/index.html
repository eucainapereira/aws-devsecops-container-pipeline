Controles de Arquitetura AWS & Container

Especificações implementadas via Terraform e Dockerfile para conformidade CIS/AWS Foundational Security.

  • ✅
    EC2 IMDSv2 Obrigatório (http_tokens = "required")

    Mitiga ataques de SSRF que tentam roubar credenciais temporárias da IAM Role via endpoint 169.254.169.254.

  • ✅
    Volume EBS Raiz Criptografado (GP3)

    Proteção de dados em repouso ativada por padrão no provisionamento da instância Amazon Linux 2023 (t3.micro).

  • ✅
    Security Group Restritivo (Sem Porta 22 / SSH)

    Apenas tráfego HTTP (80/TCP) permitido na entrada. Gerenciamento e deploy feitos via agente AWS SSM e HTTPS (443).

  • ✅
    Amazon ECR com Scan on Push & Lifecycle Policy

    Criptografia AES256, varredura automática de imagens e retenção apenas das últimas 3 imagens para otimização de custos (Free Tier).

  • ✅
    Container Nginx Alpine Non-Root (Porta 8080)

    Imagem enxuta com versão pinada, atualização de pacotes de segurança no build e execução sem privilégios de root.
